DHBW TINFO25 — Rapla Calendar Feed

This page hosts an automatically updated iCalendar feed for the DHBW TINFO25 lecture timetable. The feed is refreshed every Sunday from rapla.dhbw.de.

Subscribe

Copy the URL below and add it as an internet calendar subscription in your calendar app. Do not import it manually — subscribe so updates arrive automatically.

https://hwnest25.github.io/rapla-exporter/dhbw_tinfo25.ics

Outlook

  1. File → Account Settings → Internet Calendars → New
  2. Paste the URL above and click Add

Google Calendar

  1. Other calendars → + → From URL
  2. Paste the URL and click Add Calendar

Apple Calendar

  1. File → New Calendar Subscription
  2. Paste the URL and click Subscribe
